# AI Bilim ve Teknik

Yapay zekanın dünyada getireceği faydalar, yenilikler ve başarılarını içeren modern bir web sitesi.

## Özellikler
- **Next.js 14** (App Router)
- **Tailwind CSS** (Modern Dark Theme)
- **Framer Motion** (Gelişmiş Animasyonlar)
- **Lucide Icons** (Vektörel İkonlar)

## Kurulum
```bash
npm install
npm run dev
```

Bu proje Vercel üzerinde doğrudan yayınlanmaya uygundur.
